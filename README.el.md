*Προσομοιωμένη ημέρα, φανταστικοί χαρακτήρες: είναι η μακέτα `demo/index.html`, νυχτερινό θέμα. [Στατική εικόνα σε υψηλή ανάλυση](docs/img/wakilarium-hero.png).*

**Δείτε τους πράκτορές σας να δουλεύουν.** Το Wakilarium είναι μια ανοιχτή μορφή συμβάντων, το *Wakil Event*, και ένα web component χωρίς εξαρτήσεις που ανεβάζει στη σκηνή οποιονδήποτε πράκτορα ΤΝ: διάδρομοι ανά επάγγελμα, ένας δακτύλιος ανά πράκτορα, ο άνθρωπος σε χρυσό, οι επισκέπτες με διακεκομμένη γραμμή, οι ανταλλαγές και οι αποφάσεις που κολυμπούν μπροστά στα μάτια σας, ζωντανά και σε επανάληψη είκοσι τεσσάρων ωρών. Μια δημόσια σελίδα δείχνει την ίδια σκηνή χωρίς καμία εσωτερική λεπτομέρεια.

«Wakil» (وكيل) είναι ο εντολοδόχος, αυτός που ενεργεί εξ ονόματος άλλου· «-arium», ο τόπος όπου τον παρατηρούμε.

> Κατάσταση στις 19/10/2026: **παρτίδα 0**. Η μορφή v0.1, το σχήμα της και μια διαδραστική μακέτα δημοσιεύονται εδώ για ανασκόπηση. Το component, ο συλλέκτης και οι προσαρμογείς έρχονται με την παρτίδα 1. Τίποτα δεν εγκαθίσταται ακόμη.

## Δείτε τη μακέτα

Ανοίξτε το `demo/index.html` σε έναν περιηγητή (ή σερβίρετε τον φάκελο `demo/`). Αναπαράγεται μια φανταστική ημέρα: ρολόι, ταχύτητα, χρονογραμμή, κόστος ημέρας, εκκρεμείς αποφάσεις, διακόπτης «δημόσια προβολή», θέματα νύχτας και ημέρας, γαλλικά και αγγλικά. Καμία αίτηση δικτύου: όλα είναι μέσα στη σελίδα.

## Η μορφή σε μία γραμμή

```json
{"v":"0.1","ts":"2026-10-19T10:05:00+02:00","kind":"decision.open","actor":{"id":"chef","name":"Camille Aubert","role":"chef de cabinet","lane":"direction"},"target":{"id":"fondateur"},"title":"Publier la page d'offre ?","public_title":"propose une décision","status":"pending"}
```

Δέκα είδη συμβάντων (`run.start`, `run.end`, `tool`, `message`, `decision.open`, `decision.made`, `visitor`, `launch`, `cost`, `note`), ένας δράστης με τον διάδρομό του και ένας κανόνας: **ό,τι είναι ιδιωτικό μένει ιδιωτικό**. Τα `title`, `detail`, `attrs` και `cost` δεν φτάνουν ποτέ σε δημόσια προβολή· μόνο το `public_title` (ή μια γενική ετικέτα) μπορεί να εμφανιστεί. Πλήρης προδιαγραφή: [`docs/wakil-event-v0.1.md`](docs/wakil-event-v0.1.md) (στα γαλλικά) · σχήμα: [`schema/wakil-event-0.1.schema.json`](schema/wakil-event-0.1.schema.json).

## Τι προβλέπεται

| Παρτίδα | Περιεχόμενο |
|---|---|
| 0 | όνομα, μορφή v0.1, σχήμα, μακέτα (αυτό το αποθετήριο σήμερα) |
| 1 | component `<wakil-arium>` (Canvas 2D, ESM + IIFE, npm και CDN), συλλέκτης `wakil-collect` (Python: `POST /events`, παρακολούθηση αρχείου, OTLP/HTTP, SQLite, `GET /state`, δημόσια σελίδα με διακριτικό, `demo`), προσαρμογέας hooks του Claude Code, φιλοξενούμενη επίδειξη |
| 2 | προσαρμογείς OpenTelemetry GenAI / OpenInference, AG-UI, σύνδεσμοι πρακτόρων αγορών· μετάβαση των ενυδρείων του Zelij Core και της πλατφόρμας του εκδότη στο component, χωρίς παλινδρόμηση |

Οι πίνακες αντιστοίχισης (Claude Code, OpenTelemetry, AG-UI, Zelij Core…) βρίσκονται ήδη στην προδιαγραφή: ανασκοπήσεις και συνεισφορές προσαρμογέων είναι ευπρόσδεκτες πριν από τον κώδικα.

## Τι δεν θα κάνει ποτέ το Wakilarium

Να αντιγράψει το περιεχόμενο ενός prompt ή μιας απάντησης· να δείξει ιδιωτική λεπτομέρεια σε δημόσια σελίδα· να καλέσει ιδιωτική διεύθυνση από ληφθέν συμβάν· να εκτελέσει οτιδήποτε. Αποθηκεύει και δείχνει.

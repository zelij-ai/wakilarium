Journée simulée. Dans votre installation, chaque carte est un Wakil Event réel, émis par vos propres agents. L'or, c'est l'humain : rien de ce qui engage ne se fait avant sa décision. Un événement, une ligne.

Le Wakil Event dit qui a fait quoi, quand, vers qui, avec quel coût et quel état. Ce qui est privé le reste : seul le titre public peut sortir.

{"v":"0.1","ts":"2026-10-19T10:05:00+02:00","kind":"decision.open",
 "actor":{"id":"chef","name":"Camille Aubert","role":"chef de cabinet","lane":"direction"},
 "target":{"id":"fondateur"},
 "title":"Publier la page d'offre ? Options, risques et retour arrière dans le paquet.",
 "public_title":"propose une décision","status":"pending"}
kind

run.start · run.end · tool · message · decision.open · decision.made · visitor · launch · cost · note

actor

id, name, role, lane, kind (agent · human · service · visitor). L'humain est dessiné en or.

privé

title, detail, attrs, cost : jamais sur une vue publique. public_title ou un libellé générique, rien d'autre.

Vos données restent chez vous.

Le collecteur tourne sur votre machine ou votre serveur. Il ne sort pas sur le réseau, il n'exécute rien : il range et il montre. La page publique est une projection sans détail, que vous ouvrez et coupez d'un clic.
